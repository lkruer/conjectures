# Problems

[Browse the proof index](../README.md#proof-index)

Each proof belongs in `erdos-<number>/`, where `<number>` is the Erdős Problems ID without leading zeros. Related manuscripts and formalizations for the same problem stay together.

No problem folders have been added yet. The first PDF will get its own page using the [problem template](../templates/problem/).

See [Adding and updating a proof](../CONTRIBUTING.md) for the upload workflow.
