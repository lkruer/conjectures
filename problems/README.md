# Problems

[Browse the proof index](../README.md#proof-index) · [Upload inventory](../docs/upload-inventory.md)

Manuscripts are available for Erdős problems **14, 96, 196, 272, 354, and 944**. Each folder contains its problem page, original manuscript PDF, Lean source record, and draft submission notes.

Problem 14 includes both parts in one PDF and two Lean files. Problem 354 covers part I. Problem 272 currently has a PDF and is awaiting its Lean counterpart.

New problems use `erdos-<number>/` without leading zeros. See [Adding and updating a proof](../CONTRIBUTING.md) and the [problem template](../templates/problem/).
